### Requirements

- Windows 10 / Windows 11
- .NET Runtime (if required)

1. Download here (Gdrive link) https://drive.google.com/drive/folders/1Cc8dec6KmfXOsF8EWgrl5kuZJmdC3MEU?usp=drive_link.
